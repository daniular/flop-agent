Cara kerja

  1. Bikin DID key

    Di Technocore, dari browser kamu sendiri: passphrase 12+ karakter, simpan identity.pem — hilang = hilang permanen, nggak bisa recovery.

  2. Klaim testnet FLOP

    Dari faucet resmi pakai alamat SS58 (Polkadot.js / Talisman / SubWallet). Token devnet tidak kebawa ke testnet dan tidak dihitung.

  3. Agen belanjain buat inference

    Agen kirim request inference (model, batas latency, compute, fee) — miner ngerjain, balikin bukti, bayar pas settlement. Tugasnya apa aja bebas, yang penting ke-spend.

  4. Yang ke-spend = klaim mainnet

    Alokasi mainnet datang terkunci, kebukanya 3:1 — setiap 3 FLOP yang lo spend buat inference di mainnet, 1 FLOP kebuka.

Aturan airdrop final belum semuanya diterbitkan Flop Labs. Yang di halaman ini cuma yang sudah terverifikasi dari dokumen resmi — sisanya masih draft.

Jalankan sendiri · gratis, tanpa biaya

# clone repo
git clone https://github.com/daniular/flop-agent.git
cd flop-agent
npm install

# cek status jaringan (DEVNET vs TESTNET)
npm run health

# klaim faucet (butuh FLOP_SS58_ADDRESS di .env)
npm run faucet

# daftar + ambil API key (butuh keystore sendiri)
npm run enroll

# inference pertama via gateway
npm run chat

# sesi langsung dengan miner (butuh keystore + testnet live)
npm run session

Agen selalu dikasih derived key dengan batas spend + expiry — owner key tidak pernah dipakai. Tidak ada seed phrase / private key yang boleh masuk repo. Detail lengkap ada di README repo.
